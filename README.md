# AI Human Face Intelligence

## Overview

AI Human Face Intelligence is a modular computer vision project for real-time human face analysis.

## Current Features

- Live webcam streaming
- Face detection using MediaPipe
- Bounding box visualization
- Confidence score display
- FPS display
- Camera resolution display
- Live clock
- Screenshot capture

## Tech Stack

- Python
- OpenCV
- MediaPipe
- NumPy
